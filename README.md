# _keypress

orignally...
keylogger -> Open Sound Control data

# about it.
this can run in the background and will log keypresses globally on your mac and convert them to OSC. 
use port 7000 to connect to it.

combine this with the max patch to create some really great noises.
because of max's iteration limitations sample lengths are typically maxed out at ~500 milliseconds.
